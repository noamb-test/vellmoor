FireRed battle interface (from the pret/pokefirered project on GitHub)

backgrounds/   20 battle backgrounds, 240x112, with the ground platforms built in
               (grass, long grass, cave, mountain, sand, water, pond, underwater, building,
                and indoor versions for gyms, leaders, Lorelei, Bruno, Agatha, Lance, champion...)
boxes/         message_box.png  - the blue text box
               command_box.png  - text box + FIGHT/BAG/POKEMON/RUN panel
               move_box.png     - move list panel + PP/type panel
healthboxes/   opponent.png, player.png (with EXP bar), hp_bars_and_status.png (HP bar pieces,
               status badges), level_up_banner.png
original_files/ every source file as stored in the game (tiles, palettes, tile maps, fonts,
               text window frames)
preview_battle_screen.png  everything put together on the grass background

Everything is at the Game Boy Advance's original size (screen 240x160). Scale by whole numbers
(2x, 3x, 4x) with pixelated rendering to keep it crisp.
